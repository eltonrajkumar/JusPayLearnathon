JUSPAY Learnathon
Amazon Automation

##  Technologies Used

- **Programming Language:** Java
- **Automation Framework:** Selenium WebDriver
- **IDE:** IntelliJ IDEA
- **Browser:** Google Chrome
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Selenium Concepts Covered

This project provides hands-on practice with:

- WebDriver initialization and browser management
- Locating elements using ID, class name, XPath and CSS selectors
- WebElement interactions (`click()`, `sendKeys()`, `clear()`)
- Explicit waits using `WebDriverWait`
- Expected Conditions
- Handling multiple browser tabs and windows
- Handling dropdowns using Selenium's `Select` class
- Interacting with custom dropdowns
- Switching between iframes
- Handling dynamically loaded elements
- Inspecting HTML elements using Chrome DevTools



## Prerequisites

Make sure you have installed:

1. Java JDK
2. IntelliJ IDEA
3. Google Chrome
4. Maven
5. Git

## To clone

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/JusPayLearnathon
```

**2. Open the project**

Open the cloned folder in IntelliJ IDEA.

**3. Install Maven dependencies**

```bash
mvn clean install
```

**4. Run the Java automation program**

Run the `Juspay.java` file from IntelliJ IDEA.
